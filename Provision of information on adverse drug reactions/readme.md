<h2> # Project.4 - 의약품 이상 사례 데이터를 이용한 정보 격차 해소 </h2>

### Background
  일반의약품(OTC)은 처방전 없이 구매가 가능하지만, <br>
  정작 소비자는 구체적인 부작용 정보나 복용량 기준을 확인하기 어렵다. <br>

  FDA FAERS(자발적 이상사례 보고) 데이터를 분석하여, 각 성분 / 특성 별 의약품에 따라 <br>
  두드러지는 부작용 신호와 라벨 기준 복용 정보를 파악하고, <br>
  이를 소비자가 이해하기 쉬운 개인화 리포트 형태로 전달하는 시스템을 구축한다. <br>

  결과적으로 전문 지식 없이도 소비자가 자신에게 필요한 안전 정보에 바로 접근할 수 있도록 하여,<br>
  전문가와 일반 소비자 사이의 정보 격차를 줄이는 것을 목적으로 한다.<br><br>

### Summary

  - (1) Data information
    - Kaggle 소스의 FAERS 원본 데이터 (2015 ~ 2026년, 약 528,000행)
    - 원본 데이터 주요 변수: 나이, 성별, 반응(reaction) 유형, 심각도(사망/입원/생명위협/장애/회복), 보고 연도, 의약품 브랜드명
    - 원본 데이터에는 ATC 코드가 없어, 성분/브랜드명 기반으로 별도 분류가 필요한 상태

  - (2) Data Preprocessing
    - 1972년 이전부터 사용된 성분을 카테고리별로 승인한 "OTC monograph", 처방약에서 OTC로 전환된 성분 목록이 포함되어 있는 "Orange Book" 을 통한 일반의약품 필터링
    - WHO ATC 코드 분류 체계 자동 부여를 위해, FDA의 약효 분류 기준(EPC)으로 매칭
    - 분석 대상 데이터를 18,273행, ATC 코드 그룹 (A/B/D/M/N/R/S 그룹)으로 확정 
    - 중복값, 결측치 유지, 이상치 유지, 생물학적으로 불가능한 값 제거
    - 각 브랜드의 의약품 주 성분 별 부작용 동일 양상을 토대로, 제품명에 따른 정보 제공을 위한 그룹화 (아세트아미노펜 포함 그룹을 대표 예시로 채택)

  - (3) Statistics, Visualization Insights
    - 전체 부작용 데이터 분석 및 양상 확인
    - ATC 그룹별 심층 분석
      - A/B/D/M/N/R/S 그룹 별 분석 및 시각화 인사이트 정리
      - 각 그룹 내 세부 성분/제제 단위로 재그룹화 후 분석 및 시각화 인사이트 정리
    - 제품명에 따른 정보 제공을 위한 대표 예시(아세트아미노펜 포함 그룹) 분석
      - 아세트아미노펜 포함 그룹을 주 성분이 동일한 그룹으로 나누어 분석
      - 해당 분석 제품명 (FAERS 원본 데이터 내 제품명)과, 한국 제품명 매칭 밎 정리

  - (4) dashboard / service
    - n8n 웹훅 기반 단일 호출(single-call) 워크플로우 구축 (초기 대화형 챗봇 구조에서 발전)
    - 사용자가 나이·성별·의약품 브랜드명을 한 번에 입력하면, GPT-4o-mini 에이전트가 구조화된 한국어 JSON 리포트로 응답
    - 출력 스키마: `유의해야_할_부작용`(키워드 나열), `권장_복용량`(라벨 기준 수치), `간단한_유의점_설명`(~아요/~어요체 자연스러운 문장 흐름)
    - 결정적 코드 단계(`brand_local_prelookup`)로 브랜드/성분명을 먼저 로컬 매칭하고, 실패 시에만 에이전트가 웹서치로 폴백하는 구조
    - 아세트아미노펜 브랜드 전용 tool node(`apap_brand_group_lookup`, `apap_brand_dose_reference_lookup`) 추가로 브랜드-성분조합 단위 세부 인사이트 및 raw 라벨 용량 정보 제공
    - QA 테스트 콘솔과 가드레일 스캐너를 구성하여 수치 인용 오류, 통계치 노출, 어투 규칙 위반 등을 사전 점검

  - (5) Report
    - ATC 그룹별 인사이트를 통합한 구조화 JSON 지식베이스 구축 (`FAERS_OTC_인사이트_통합.json`) - 29개 서술형 필드에서 구체적 퍼센트 수치를 제거하고 정성적 표현으로 재작성
    - 나이·성별 교차 통계 파일(`faers_by_atc_age_sex.json`)을 pandas groupby로 별도 생성, `reference_info`(FDA 라벨 기준 사실 정보)는 통계 수치와 분리하여 소비자에게 노출 가능한 항목으로 구분
    - FAERS가 자발보고 데이터라는 한계(중증 사례일수록 과대보고되는 편향)를 리포트 문구 설계 단계에서부터 반영 - 사망률/비율 등 원본 통계치는 노출하지 않고 반응 키워드 중심으로만 안내

  - (6) Feedback  *(초안 - 실제 소감/피드백에 맞게 다듬어 주세요)*
    - FAERS 자발보고 데이터의 보고 편향(under-reporting, 중증 편향) 문제를 분석 설계 초반부터 리포트 문구 규칙에 명시적으로 반영해야 인사이트의 오독을 줄일 수 있었다.
    - '통계적 신호 탐지'와 '소비자 대상 안내'라는 두 목적이 혼재되지 않도록, PRR/신뢰구간 등 통계 산출물과 최종 소비자 문구 사이에 명확한 변환 규칙(가드레일)이 필요했다.
    - 표본이 작은 그룹(B군, S군 등)일수록 정성적 표현으로 전환하는 기준을 먼저 정하고 나머지 그룹에 일관되게 적용하는 순서가 효율적이었다.

  - (7) Review  *(초안 - 실제 소감/피드백에 맞게 다듬어 주세요)*
    - 소비자 대상 서비스라는 특성상, 모델 성능보다 '틀린 안심'과 '과도한 불안 유발'을 동시에 피하는 문구 설계가 핵심 난이도였다.
    - 아세트아미노펜처럼 브랜드 수가 많고 성분조합이 복잡한 경우, 통계 인사이트(성분조합 단위)와 라벨 사실 정보(브랜드 단위)를 분리된 두 도구로 나눠 서로 다른 신뢰 수준을 유지한 설계가 유효했다.
    - 세부 인사이트가 부족한 저표본 성분조합(5건)에 대한 처리 기준을 아직 확정하지 못한 상태로, 데이터가 더 쌓이기 전까지는 일반 정보로 안내하는 fallback 규칙을 유지하는 것이 자연스러운 다음 단계로 보인다.
