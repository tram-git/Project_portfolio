<h2> # Project.4 - 의약품 이상 사례 데이터를 이용한 정보 격차 해소 </h2>

### Background
  일반의약품(OTC)은 처방전 없이 구매가 가능하지만, <br>
  정작 소비자는 구체적인 부작용 정보나 복용량 기준을 확인하기 어렵다. <br>

  FDA FAERS(자발적 이상사례 보고) 데이터를 분석하여, 각 성분 / 특성 별 의약품에 따라 <br>
  두드러지는 부작용 신호와 라벨 기준 복용 정보를 파악하고, <br>
  이를 소비자가 이해하기 쉬운 개인화 리포트 형태로 전달하는 시스템을 구축한다. <br>

  결과적으로 전문 지식 없이도 소비자가 자신에게 필요한 안전 정보에 바로 접근할 수 있도록 하여,<br>
  전문가와 일반 소비자 사이의 정보 격차를 줄이는 것을 목적으로 한다.<br><br>

### Summary

  - (1) Data information
    - Kaggle 소스의 FAERS 원본 데이터 (2015 ~ 2026년, 약 528,000행)
    - 원본 데이터 주요 변수: 나이, 성별, 반응(reaction) 유형, 심각도(사망/입원/생명위협/장애/회복), 보고 연도, 의약품 브랜드명
    - 원본 데이터에는 ATC 코드가 없어, 성분/브랜드명 기반으로 별도 분류가 필요한 상태

  - (2) Data Preprocessing
    - 1972년 이전부터 사용된 성분을 카테고리별로 승인한 "OTC monograph", 처방약에서 OTC로 전환된 성분 목록이 포함되어 있는 "Orange Book" 을 통한 일반의약품 필터링
    - WHO ATC 코드 분류 체계 자동 부여를 위해, FDA의 약효 분류 기준(EPC)으로 매칭
    - 분석 대상 데이터를 18,273행, ATC 코드 그룹 (A/B/D/M/N/R/S 그룹)으로 확정 
    - 중복값, 결측치 유지, 이상치 유지, 생물학적으로 불가능한 값 제거
    - 각 브랜드의 의약품 주 성분 별 부작용 동일 양상을 토대로, 제품명에 따른 정보 제공을 위한 그룹화 (아세트아미노펜 포함 그룹을 대표 예시로 채택)

  - (3) Statistics, Visualization Insights
    - 전체 부작용 데이터 분석 및 양상 확인
    - ATC 그룹별 심층 분석
      - A/B/D/M/N/R/S 그룹 별 분석 및 시각화 인사이트 정리
      - 각 그룹 내 세부 성분/제제 단위로 재그룹화 후 분석 및 시각화 인사이트 정리
    - 제품명에 따른 정보 제공을 위한 대표 예시(아세트아미노펜 포함 그룹) 분석
      - 아세트아미노펜 포함 그룹을 주 성분이 동일한 그룹으로 나누어 분석
      - 해당 분석 제품명 (FAERS 원본 데이터 내 제품명)과, 한국 제품명 매칭 밎 정리

  - (4) dashboard / service
    - n8n 웹훅 기반 단일 호출(single-call) 워크플로우 구축 (대화형 챗봇 구조에 적용)
    - 사용자가 나이·성별·의약품 명을 입력하면, n8n 워크플로우 에이전트를 통해 구조화된 한국어 JSON 리포트로 응답
    - 출력 스키마: `유의해야_할_부작용`(키워드 나열), `권장_복용량`(라벨 기준 수치), `간단한_유의점_설명`(자연스러운 문장 흐름)
    - 브랜드/성분 명을 먼저 로컬 매칭하고, 실패 시에만 에이전트가 웹서치로 폴백하는 구조
    - 각 브랜드/성분 명 검색을 통한 해당 정보 전달 방식 채택
    - 자주 보고된 부작용, 연령 별 주의사항, 복용 방법 등 검색 결과 페이지 구성

  - (5) Report
    - ATC 그룹별 인사이트를 통합한 구조화 JSON 베이스 구축 (`FAERS_OTC_인사이트_통합.json`)
    - FAERS가 자발보고 데이터라는 한계를 리포트 문구 설계 단계에서부터 반영 - 사망률/비율 등 원본 통계치는 노출하지 않고 반응 키워드 중심으로만 안내
    - 사용자의 입력에 따른 간단한 정보 제공을 위한 챗봇 시스템 구성
    - 의약품, 제품 명에 따른 구체적인 정보 전달을 위한 검색 기능 및 결과 페이지 구성
    - 사용자로 하여금, 부작용 정보를 미리 파악하고 큰 피해를 예방할 수 있는 대시보드 구현 (적확한 처방을 내리는 것이 아님을 고지)

  - (6) Feedback
    - FAERS 자발보고 데이터 전체를 한 번에 분석하는 것이 아니라, WHO ATC 코드 분류 - 세부 성분/제제 단위 그룹화를 통한 세분화가 분석에 용이하였다.
    - 추가 예정
   
  - (7) Review
    - 현 상황에서는 브랜드 명 처리가 아세트아미노펜 그룹에 한정되어 있는 상태. 더 진행한다면, 같은 방식으로 확장 가능할 것이다.
    - 프로젝트 진행 간 분석 단계를 더 빠르게 구체화하였다면, 전처리 단계에서 많은 시간을 소요하지 않았을 것이다.
    - 소비자 대상 서비스라는 특성상, 모델 성능보다 '틀린 안심'과 '과도한 불안 유발'을 동시에 피하는 문구 설계가 핵심이었다.
    - 인사이트(성분조합 단위)와 라벨 사실 정보(브랜드 단위)를 나눠 서로 다른 신뢰 수준을 유지한 설계가 유효했다.
